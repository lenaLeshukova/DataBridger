
# DataBridger (HW) 📊

Универсальный инструмент для анализа личных финансов. Проект считывает данные из банковских выписок (Excel), анализирует категории кешбэка, формирует детальные отчеты и отображает сводный дашборд с курсами валют и ценами акций.

## 🛠 Основной функционал

1.  **Личный дашборд (`views.py`)**: 
    *   Приветствие пользователя в зависимости от времени суток.
    *   Сводка по картам (траты и кешбэк 1%).
    *   Топ-5 самых крупных транзакций за месяц.
    *   Актуальные курсы валют (USD/EUR) и котировки акций (через API).
2.  **Аналитика кешбэка (`services.py`)**: 
    *   Анализ выгодных категорий за выбранный месяц и год.
    *   Использование элементов функционального программирования.
3.  **Генерация отчетов (`reports.py`)**: 
    *   Фильтрация трат по категории за последние 90 дней.
    *   **Умный декоратор**: автоматическое сохранение любого отчета в JSON-файл в папку `reports/`.
4.  **Утилиты (`utils.py`)**: 
    *   Безопасное чтение Excel-файлов с автоматической конвертацией дат.

## 📁 Структура проекта

```text
DataBridger/
├── data/               # Входящие данные (operations.xlsx)
├── reports/            # Сгенерированные JSON-отчеты
├── src/                # Исходный код
│   ├── main.py         # Точка входа
│   ├── views.py        # Логика дашборда
│   ├── services.py     # Аналитические сервисы
│   ├── reports.py      # Модуль отчетов и декоратор
│   └── utils.py        # Вспомогательные функции
├── tests/              # Набор модульных тестов (Pytest)
├── .env                # API-ключи (необходимо создать)
├── .gitignore          # Список исключаемых файлов для Git
├── conftest.py         # Конфигурация и фикстуры для Pytest
├── poetry.lock         # Фиксация версий зависимостей (Poetry)
├── pyproject.toml      # Основные настройки проекта и зависимостей
├── README.md           # Документация
├── requirements.txt    # Список зависимостей (для pip)
├── services.log        # Лог-файлы приложения
└── user_settings.json  # Настройки валют и акций пользователя
```
## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:lenaLeshukova/DataBridger.git
```
2. Установите зависимости:
```
bash
pip install -r requirements.txt
```
3. Настройте переменные окружения:
```
Создайте файл .env в корневой папке.
Скопируйте содержимое из .env.example в .env.
Замените your_api_key_here на ваш реальный API ключ от apilayer.com
```
## Тестирование
```
Проект покрыт модульными тестами с использованием библиотеки `pytest`  и `unittest.mock`. Тесты проверяют корректность работы функций маскировки данных, фильтрации и сортировки банковских операций. Мокирование (замену) ответов внешнего API.
```
### Запуск тестов
Примечание: Тесты используют фикстуры и параметризацию для обеспечения чистоты кода и проверки различных граничных условий.

Для запуска всех тестов выполните команду:
```bash
pytest
* sort_by_date
```
Отчет о покрытии (Coverage)
Вы также можете проверить покрытие кода тестами (если установлена библиотека pytest-cov):
```
pytest --cov --cov-report=html
```
